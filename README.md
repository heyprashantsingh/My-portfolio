# Prashant Singh portfolio source

## Put these files in your project

Copy the contents of this folder into the root of your Vite + React project. If you are starting from scratch, use this folder as the project root.

## Run it

```bash
npm install
npm run dev
```

## Add your video

Put the video at `src/assets/portfolio-bg.mp4`.

## Edit your details

Change the email, social URLs, and project screenshot paths in `src/data/site.js`.

## Share code

Open the Code section, edit the snippet, choose a language, then select **Share code**. The generated URL contains the code and language in its URL fragment; no backend or database is used. Open the link in another tab to see the shared-code view. Keep snippets reasonably short because all content is encoded in the URL.
